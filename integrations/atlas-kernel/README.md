# Atlas Integration Kernel

Núcleo executável e seguro de interoperabilidade do Atlas Vivo MILK.

- modelos Pydantic e porta de publicação;
- ROR, Zenodo, ORCID, DataCite, Forgejo e FIWARE;
- dossiês IGAC/WIPO sem inventar registos;
- dez agentes Mistral para toda a engenharia;
- dry-run e hashes por omissão;
- estado factual da migração por manifesto.

Ver `docs/developer/web-integration.md`.
